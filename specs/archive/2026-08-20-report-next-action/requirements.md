# Requirements

## NEXT-001 A risk item carries a next action or an accepted status

Source: `WEIGHT-004` in the archived change
`2026-08-20-risk-weighted-security-reporting`, which requires a reported
material risk to state "the affected scope, realistic consequence, and
corrective action or accepted status clearly enough to act on".

The default risk item names scope, consequence, and either the next action or
the accepted status. Because the note holds only material risks, the next action
is not conditional on adding information.

Acceptance: every risk item in a note states a corrective action or an explicit
accepted status.

Example: a pre-existing agent permission finding reported during an unrelated
task names the missing approval boundary and the step that would add it, instead
of ending with "pre-existing and outside this task".
