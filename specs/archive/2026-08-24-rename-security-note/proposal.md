# Rename the baseline security note

## Problem

The current heading sounds stronger than the neutral closing note it labels.
The normative baseline also relies heavily on em dashes, which makes the
compact rules read more stylized than necessary.

## Goal

Use a neutral heading that identifies the baseline as its source, preserve that
behavior in model evidence, and replace em dashes with ordinary punctuation
without changing any rule's meaning.

## Non-goals

Do not change which risks qualify, when the note appears, what it contains, or
how risks are prioritized. Do not rewrite archived change records.

## Compatibility

Exact-match consumers of the heading must accept its new wording. All other
reporting behavior remains unchanged.
